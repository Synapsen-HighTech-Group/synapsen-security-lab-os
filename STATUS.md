# Project Status

**Public project status: `IN DEVELOPMENT`**

## Verified milestone

The S07 release-chain evidence is sealed and identifies the final artifact
revision as `V24T-BRANDING-R1`.

This repository treats that as a verified engineering milestone, not as a claim
that the entire SSLOS product is finished or generally released.

## Current public-source scope

Included:

- S07 first-party release-verifier source;
- deterministic manifest tooling;
- first-party SPDX generator/validator source;
- verification UI contract/view-model;
- public-safe acceptance/SPDX evidence;
- original safe release metadata, detached signature, SBOM and package list.

Not included:

- 5+ GB ISO;
- VirtualBox images;
- private path-bearing evidence originals;
- key custody media or recovery material;
- complete distribution build workspace;
- third-party vendored wheels;
- every visual/design/runtime asset.

Accordingly, **full source-to-ISO reproducibility is not asserted** by this
public snapshot.
